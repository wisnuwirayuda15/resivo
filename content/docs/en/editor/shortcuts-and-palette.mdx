## The modifier key [#modifier]

<Tabs items={["Windows", "macOS"]}>
<Tab value="Windows">

On Windows and Linux the modifier is <Kbd>Ctrl</Kbd>, so the command palette is

<Kbd>Ctrl</Kbd> + <Kbd>K</Kbd>.

</Tab>
<Tab value="macOS">

On a Mac the modifier is <Kbd>⌘</Kbd>, so the command palette is <Kbd>⌘</Kbd> +

<Kbd>K</Kbd>.

</Tab>
</Tabs>

The rest of this page writes <Kbd>Ctrl</Kbd>. Read <Kbd>⌘</Kbd> on a Mac.

## The shortcuts [#shortcuts]

Open **Keyboard shortcuts** from the application menu, or from the command
palette, for the same list inside the app. It lists only what is bound.

Anywhere in the app:

| Keys                                              | Does                                         |
| ------------------------------------------------- | -------------------------------------------- |
| <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd>                    | Opens the command palette                    |
| <Kbd>Ctrl</Kbd> + <Kbd>B</Kbd>                    | Collapses or expands the sidebar             |
| <Kbd>Ctrl</Kbd> + <Kbd>Z</Kbd>                    | Undoes the last change to the resume         |
| <Kbd>Ctrl</Kbd> + <Kbd>Shift</Kbd> + <Kbd>Z</Kbd> | Redoes (also <Kbd>Ctrl</Kbd> + <Kbd>Y</Kbd>) |

In the Markdown and CSS panes:

| Keys                           | Does                                         |
| ------------------------------ | -------------------------------------------- |
| <Kbd>Ctrl</Kbd> + <Kbd>Z</Kbd> | Undoes typing, a step at a time              |
| <Kbd>Ctrl</Kbd> + <Kbd>F</Kbd> | Finds in the pane                            |
| <Kbd>F1</Kbd>                  | Opens the code editor's own list of commands |

On the paper, in Visual mode:

| Keys              | Does                                              |
| ----------------- | ------------------------------------------------- |
| <Kbd>Enter</Kbd>  | Edits the highlighted text, then keeps the change |
| <Kbd>Escape</Kbd> | Finishes editing and discards the change          |

## Why some do not work everywhere [#scope]

The code panes and the paper are not part of the page around them. The code
editor is a text editor of its own with its own bindings, and the paper is a
separate document, so a keystroke inside either does not reach the app. That
is deliberate. It means that while your cursor is in a code pane, or you are
editing a field on the paper, <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> and

<Kbd>Ctrl</Kbd> + <Kbd>B</Kbd> do nothing, and the undo shortcut undoes what you
typed there rather than the whole resume. Click outside them and the shortcut
means the app again. The buttons in the bar always act on the whole resume.

## The command palette [#palette]

<Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> opens the palette, which has a field marked
**Search commands…**. Type any part of what you want. It matches a command's
name, its description and some related words, so "folder" finds **New group**
and "dark" finds the theme command. If nothing matches it says **No command
matches that.** Choose a command with the mouse, or with the arrow keys and
Enter.

It is the quickest way to reach the rest of the app from the keyboard:

- **Create**: **New resume**, **New cover letter** and **New group**.
- **Go to**: **All resumes**, **Archived**, **Templates**, **Images**,
  **Fonts**, **Settings**, **About Resivo** and **Documentation**.
- **This app**: the light or dark theme, **Toggle sidebar**, **Keyboard
  shortcuts**, **Take the tour**, and a switch to the other interface language.

Words in the other language match too, so a command can be found by its English
name when the interface is in Indonesian.
