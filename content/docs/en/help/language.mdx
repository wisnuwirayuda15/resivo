title: Language
description: The language of the app and of these docs, how it is chosen and remembered, and how it differs from the language of a resume's own dates.
---

There are three different things that are called language here, and keeping them
apart avoids most confusion.

## The interface [#interface]

The language of menus, dialogs, messages and the tours. There are two: English and
Bahasa Indonesia. Each is named in its own language, so someone who has landed in
one they cannot read can still find their own.

Choose it in **Settings**, under **Language**, with **Interface language**. It
applies at once, with no reload, and it is remembered on this device.

Until you choose, Resivo uses the first of your browser's preferred languages that
it has, and English if it has none. A page is first drawn in English and switches
after it loads, so a moment of English before the other language is normal.

## The language of a resume [#resume]

Each resume has its own language, set in the **Style** tab under **Language**, in
**Document**. It formats month names, writes the end of an ongoing role, and sets
the language of the exported document. It does not translate anything you wrote,
and it is separate from the interface: a resume in French can be written in an app
set to English. See [Design tokens](/docs/design/design-tokens#language).

The names of sections the format recognises, such as Experience, are recognised in
English and in Indonesian whichever the document's language is. See
[The shape of the file](/docs/format/overview).

## These docs [#docs]

The documentation is written in both languages, at `/en/docs` and `/id/docs`.
Every page has the same address in both, so the language switch in the header
takes you to the same page in the other language.

Opening `/docs` with no language sends you to the language you chose in the app, or
to the one your browser prefers, and to English if neither applies. A link someone
shares to a page in one language always opens in that language and never changes
your choice. Choosing a language in the docs header does change it, for the app as
well.

## What is not translated [#not]

The names of the export formats, the three typefaces, and the prompts for an
assistant stay in English on purpose. A resume's own text is yours and is never
translated.
