## Tombol pengubah [#modifier]

<Tabs items={["Windows", "macOS"]}>
<Tab value="Windows">

Pada Windows dan Linux tombol pengubahnya adalah <Kbd>Ctrl</Kbd>, jadi palet
perintah adalah <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd>.

</Tab>
<Tab value="macOS">

Pada Mac tombol pengubahnya adalah <Kbd>⌘</Kbd>, jadi palet perintah adalah

<Kbd>⌘</Kbd> + <Kbd>K</Kbd>.

</Tab>
</Tabs>

Sisa halaman ini menulis <Kbd>Ctrl</Kbd>. Bacalah <Kbd>⌘</Kbd> pada Mac.

## Pintasannya [#shortcuts]

Buka **Pintasan keyboard** dari menu aplikasi, atau dari palet perintah, untuk
daftar yang sama di dalam aplikasi. Daftar itu hanya memuat yang benar-benar
terpasang.

Di mana saja di aplikasi:

| Tombol                                            | Fungsi                                           |
| ------------------------------------------------- | ------------------------------------------------ |
| <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd>                    | Membuka palet perintah                           |
| <Kbd>Ctrl</Kbd> + <Kbd>B</Kbd>                    | Menciutkan atau melebarkan bilah samping         |
| <Kbd>Ctrl</Kbd> + <Kbd>Z</Kbd>                    | Mengurungkan perubahan terakhir pada resume      |
| <Kbd>Ctrl</Kbd> + <Kbd>Shift</Kbd> + <Kbd>Z</Kbd> | Mengulangi (juga <Kbd>Ctrl</Kbd> + <Kbd>Y</Kbd>) |

Di panel Markdown dan CSS:

| Tombol                         | Fungsi                                         |
| ------------------------------ | ---------------------------------------------- |
| <Kbd>Ctrl</Kbd> + <Kbd>Z</Kbd> | Mengurungkan ketikan, selangkah demi selangkah |
| <Kbd>Ctrl</Kbd> + <Kbd>F</Kbd> | Mencari di panel                               |
| <Kbd>F1</Kbd>                  | Membuka daftar perintah milik editor kode      |

Di kertas, dalam mode Visual:

| Tombol            | Fungsi                                                 |
| ----------------- | ------------------------------------------------------ |
| <Kbd>Enter</Kbd>  | Menyunting teks yang disorot, lalu menyimpan perubahan |
| <Kbd>Escape</Kbd> | Selesai menyunting dan membuang perubahan              |

## Mengapa sebagian tidak berfungsi di mana-mana [#scope]

Panel kode dan kertas bukan bagian dari halaman di sekitarnya. Editor kode
adalah editor teks tersendiri dengan tombol bawaannya sendiri, dan kertas adalah
dokumen terpisah, jadi tombol yang ditekan di dalam keduanya tidak sampai ke
aplikasi. Itu disengaja. Artinya, selagi kursor Anda ada di panel kode, atau
Anda menyunting sebuah kolom di kertas, <Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> dan

<Kbd>Ctrl</Kbd> + <Kbd>B</Kbd> tidak melakukan apa-apa, dan pintasan urungkan
membatalkan apa yang Anda ketik di sana, bukan seluruh resume. Klik di luar
keduanya dan pintasan kembali berarti aplikasi. Tombol di bilah selalu bekerja
pada seluruh resume.

## Palet perintah [#palette]

<Kbd>Ctrl</Kbd> + <Kbd>K</Kbd> membuka palet, yang memiliki kolom bertanda
**Cari perintah…**. Ketik bagian mana pun dari apa yang Anda mau. Ia mencocokkan
nama perintah, deskripsinya, dan beberapa kata terkait, jadi "folder" menemukan
**Grup baru** dan "gelap" menemukan perintah tema. Jika tidak ada yang cocok, ia
menjawab **Tidak ada perintah yang cocok.** Pilih perintah dengan mouse, atau
dengan tombol panah dan Enter.

Ini cara tercepat menjangkau sisa aplikasi dari keyboard:

- **Buat**: **Resume baru**, **Surat lamaran baru**, dan **Grup baru**.
- **Buka**: **Semua resume**, **Diarsipkan**, **Template**, **Gambar**,
  **Font**, **Pengaturan**, **Tentang Resivo**, dan **Dokumentasi**.
- **Aplikasi ini**: tema terang atau gelap, **Buka atau tutup bilah samping**,
  **Pintasan keyboard**, **Ikuti tur**, dan pergantian ke bahasa antarmuka
  lainnya.

Kata dalam bahasa lain juga cocok, jadi sebuah perintah dapat ditemukan dengan
nama Inggrisnya saat antarmuka berbahasa Indonesia.
